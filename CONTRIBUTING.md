# Contributing to secvix

Thank you for your interest in secvix.

## Workflow

1. Fork the repository (or create a branch if you are a collaborator).
2. Open a **pull request** against `main`.
3. Wait for review. **Only the repository owner (`khushwant666`) may merge** pull requests into `main`.

Direct pushes to `main` are restricted by branch protection.

## Commits

- Use clear, conventional commit messages (`feat:`, `fix:`, `docs:`, `chore:`, etc.).
- Do not add `Co-authored-by` lines for automated tools unless the maintainer requests it.
